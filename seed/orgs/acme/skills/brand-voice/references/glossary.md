# Acme Cloud Glossary

| Use | Avoid | Note |
| --- | --- | --- |
| workflow | automation, flow, zap | A saved sequence of steps. |
| run | execution, job | One execution of a workflow. |
| step | node, action block | A single unit in a workflow. |
| connector | integration, plugin | Prebuilt link to a third-party app. |
| workspace | org, tenant, account | Customer's top-level container. |
| admin | owner, superuser | Role that manages billing and members. |
| builder | creator, power user | Role that edits workflows. |
| sign in | log in, login (verb) | "Sign-in" as a noun. |
| Approvals inbox | approval queue | Feature name, sentence case. |
