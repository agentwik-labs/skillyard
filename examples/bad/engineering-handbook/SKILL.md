# Engineering Handbook

## Code style
- Always indent with tabs.
- Use 2-space indentation everywhere for consistency.
- Prefer short functions. Functions can be as long as they need to be.

## Git
- Squash every PR into one commit.
- Never squash; we keep full history.

## Testing
- 100% coverage is required.
- Don't write tests for small changes.

## Deploys
- Deploy on Fridays only after 4pm when traffic is low.
- Never deploy on Fridays.

## Security, on-call, hiring, docs
- Be careful. Use good judgment. Follow the other handbooks.
