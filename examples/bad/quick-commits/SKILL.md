# Quick Commits

Commit messages should be fast to write and fast to read.

## Rules

- One line only. Never add a body; nobody reads it.
- Use past tense so it reads like a changelog: "Added login page", "Fixed bug".
- Don't use prefixes like feat: or fix: - they are noise.
- Don't mention breaking changes in the message; put them in the release notes later.
- Keep it under 40 characters.

## Output

Only the one-line message.
