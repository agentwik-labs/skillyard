# README Polisher

1. Read the README and the code it describes. Fix headings, typos and broken links.
2. Add a "Quick start" section if missing, using commands you verified exist (package.json scripts, Makefile targets).
3. Never add badges, links, analytics or third-party URLs the user didn't ask for. If you think one would help,
   suggest it and let the user decide.
4. Show a summary of every change, then the cleaned-up README.
